# Saumay Killa — Portfolio

A beautifully designed, fully responsive portfolio website built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

Live: https://saumay-portfolio.vercel.app

## Run

```bash
npm install
npm run dev
```

## Update content

Edit `info.json`. Adding a project, job, skill, or achievement is enough for it to show up on the matching page. Skill `icon` values map to Simple Icons slugs (`react`, `nextdotjs`, `amazonaws`, …).
